# 觉醒 AI 静态产品 Demo

这是 AI 管理服务 V2 的静态产品流程原型，仅用于确认产品范围、交互和文案。

## 打开方式

直接双击 `index.html`，或在本目录启动任意静态文件服务。Demo 仅使用原生 HTML、CSS 和 JavaScript，没有构建依赖，也不会请求真实 API、Dify、数据库或外部课程链接。

## 演示范围

- 用户侧：三个 AI 入口、商业会话澄清、课程卡片、学习路线、专业见解、历史续聊、反馈、空状态和错误状态。
- 运营侧：CLI 课程校验/发布、知识清洗批次、必要操作与错误日志、课程链接点击次数。

运营侧是流程预览，不是首版要交付的完整管理后台。所有课程与指标都是 `test_only` 合成演示数据。
