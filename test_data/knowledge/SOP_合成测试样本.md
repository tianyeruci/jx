# SOP：发布前事实核验

> 合成测试样本，仅用于文档清洗、知识库切分和问答测试，无真实业务承诺。

## 目的

在发布知识类内容前区分可引用事实、待验证假设和个人建议。

## 操作步骤

1. 标出文中的数据、人物、时间和外部结论。
2. 为每项事实登记来源与核验日期。
3. 找不到来源时改写为假设或删除。
4. 检查是否存在收益、流量或学习效果保证。
5. 由另一位检查者确认后再发布。

## 完成标准

- [ ] 所有事实均可追溯。
- [ ] 建议与事实已明确区分。
- [ ] 不包含未经证实的结果承诺。
