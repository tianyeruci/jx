# jx-now 功能与接口索引

> 状态：当前有效；自动区块由源码静态解析生成。  
> 用途：按功能、接口路径或工程入口定位最小相关范围，避免每次扫描整个仓库。  
> 不替代：需求、接口契约、数据设计和部署手册仍以各自权威文档为准。

## 1. 使用方式

1. 先读取根 `AGENTS.md`，再在本文按功能名、HTTP 路径、命令或任务名定位。
2. 先读命中的“功能阅读映射”，只打开其中列出的规范、源码和测试。
3. 开发、测试、部署、Dify 或数据任务再按项目 Skill 查询对应排障文档。
4. 只有跨功能、索引检查失败、目录/入口变化或权威文档冲突时，才扩大搜索。

接口、CLI、Worker、Compose、Dify 和发布脚本的机械清单在第 4 节自动更新；功能语义、测试范围和权威文档由第 3 节人工维护。

## 2. 修改后的同步规则

- 修改 HTTP 路径、方法、处理函数、已注册 Router、CLI、Celery 任务、Compose 服务、Dify 资产或发布/RAG 脚本后，执行：

  ```powershell
  python scripts/generate_project_index.py --write
  python scripts/generate_project_index.py --check
  ```

- 功能职责、核心实现、测试范围或权威规范改变时，同时更新第 3 节的对应行和 `docs/README.md`。
- 仅函数内部实现改变且入口、职责、测试和规范映射均未变化时，不机械改写本文。
- 生成器只读取限定的入口文件，不导入应用、不读取环境变量、不启动数据库、Redis、Dify 或容器。
