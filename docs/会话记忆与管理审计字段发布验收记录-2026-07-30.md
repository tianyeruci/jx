# 会话记忆与管理审计字段发布验收记录

> 日期：2026-07-30  
> 环境：本地 Windows 开发环境、jx 测试服务器  
> 范围：测试页本地会话复用、管理会话列表/详情字段、`business_profile.user_id` 迁移、相关文档与测试

## 1. 实施结果

- 测试页从 `message_end` 优先、`request_started` 兜底读取本地 `conversation_id`，同一用户后续发送自动复用；新建会话、选择历史会话或切换用户时切换状态。
- `business_profile` 新增可空、唯一并建立索引的 `user_id`；每次商业聊天创建或补齐。内部 `user_hash` 继续用于隔离和关联，但不再由管理会话接口输出。
- 管理会话列表取最近一条助手消息，详情按消息返回 `recommended_courses`、`professional_insight`、`recommendation_note`、`token_usage`、`first_token_ms`、`total_ms`；详情顶层重复最近助手消息的汇总。
- 推荐课程缺失返回 `[]`，专业见解和推荐理由缺失返回空字符串。历史 `expert_insight` 只读兼容，不重新生成。
- 迁移前没有原始用户 ID 的记录保持空 `user_id`，用户再次聊天后补齐。

## 2. 清洗格式核对

清洗模式按所选策略的 `supported_extensions` 校验，因此不是所有策略都支持 `.docx`、`.markdown`、`.md`、`.pdf`、`.txt`。DOCX/PDF 先解析为内部 Markdown，Markdown/TXT 按文本读取，再进入各策略自己的拆分、语义分类、脱敏和发布门禁。完整矩阵见 [清洗策略接入说明](清洗策略接入说明.md#当前策略输入格式矩阵)。
