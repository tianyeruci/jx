# AI 管理服务 V2 决策记录

> 状态：生效中（V2 唯一决策基线）  
> 生效日期：2026-07-27  
> 适用范围：AI 管理服务、Dify 应用与知识库、测试 UI、课程发布、文档清洗和服务器验证。

## 1. 基线声明

以下文件仅作为历史资料，不再直接指导开发；其中与本文或其他 V2 文档冲突的内容一律以 V2 为准：

- `AI 管理服务完整开发执行计划.md`（P1）
- `AI管理服务快速落地与测试计划.md`（P2）
- `AI管理服务当前状态与后续测试交接.md`（H）
- `AI管理服务执行计划符合性审计报告.md`（审计输入，不是需求规格）

V2 文档之间的优先顺序为：本决策记录 → `V2需求规格说明.md` → `V2产品流程与边界.md` → `V2服务开发与数据设计.md` → 专项说明与运行手册。发现冲突时必须先更新决策记录，禁止由代码或口头约定隐式改变需求。

## 2. 已冻结决定

| ID | 决定 | 理由与影响 |
|---|---|---|
| ADR-001 | 不推倒重写，在现有 FastAPI、SQLAlchemy、Celery、Dify 和测试骨架上重构。 | 降低重新引入缺陷的风险；重构前先补特征测试。 |
| ADR-002 | 先完成 V2 需求、流程、静态 Demo 和设计，再改业务代码。 | 静态 Demo 用于产品确认；Streamlit 仅用于集成测试和内部运维。 |
| ADR-003 | 用户入口固定为商业顾问、朋友圈、写作三个；不设独立课程入口。 | 课程仅由商业顾问在合适场景推荐。 |
| ADR-004 | 商业会话由本服务保存；Dify Memory 关闭；每轮动态传摘要、游标后有限历史、画像、路线进度和当前问题。 | 避免双重记忆、上下文重复和不可控增长。 |
| ADR-005 | 一个本地逻辑会话按自然日对应一个 Dify 会话段。 | 支持跨日续聊，同时便于 7 天历史与远端会话清理。 |
| ADR-006 | 原始消息默认保留 7 天；只有确认已摘要的内容才可删除。 | 摘要失败、输出无效或游标冲突时禁止删除消息。 |
| ADR-007 | 课程发布首版继续使用 CLI `dry-run/publish`，不开发课程管理后台或 validation-batches API。 | 控制首版范围；Streamlit 只展示校验和发布结果。 |
| ADR-008 | 课程点击主指标是链接点击总次数（PV）；同时保留匿名点击人数（UV）作为辅助指标。 | 每次有效签名跳转计 1 次点击；点击不代表完成课程。 |
| ADR-009 | 点击按课程、自然日汇总，不保存逐次点击明细。 | 满足次数统计；降低隐私、存储和日志风险。Redis 同时损坏时可能少计，属已接受限制。 |
| ADR-010 | 后台可查看必要操作和错误事件；完整调试日志输出结构化 JSON 到 stdout。 | 事件表不保存对话正文、密钥、真实用户 ID 或敏感文件内容。 |
| ADR-011 | 后台日志和统计接口使用独立 `X-Admin-Token`；Streamlit 仅绑定服务器回环地址。 | 将运维权限与普通内部调用权限隔离。 |
| ADR-012 | 清洗默认限制为单文件 50MB、每批最多 10 个、总计不超过 500MB。 | 同时校验扩展名、声明 MIME、文件头和路径。 |
| ADR-013 | Redis 缓存可回源数据库；分布式会话锁不可降级为多进程无效的内存锁。 | Redis 不可用时，涉及会话状态写入的请求返回可重试错误。 |
| ADR-014 | 服务器采用当前实例原地更新测试，使用不可变镜像、备份和明确回滚点；禁止容器内热改代码。 | 每次修复均在本地完成、测试、构建新镜像后重新部署。 |
| ADR-015 | V2 为唯一有效基线；P1/P2/H 保留但标记历史，不删除。 | 保留审计链，同时避免多套计划并行生效。 |

## 3. 明确不做

- 不建设面向最终用户的 Web 管理后台；Streamlit 不是正式产品界面。
- 不保存逐次课程点击事件，不用点击自动推进学习路线。
- 不让朋友圈和写作入口保存业务会话历史。
- 不允许模型直接生成或替换课程正式链接。
- 不在 V2 首版引入动态清洗策略平台、LLM Judge 平台或复杂发布审批系统。
- 不自动执行生产发布、Dify 写入或 Git push；均需对应授权和运行手册门禁。

## 4. 变更规则

任何影响入口、会话记忆、数据保留、课程发布、点击口径、权限或服务器拓扑的变更，都必须：

1. 新增 ADR 编号，写明替代的旧决定；
2. 同步更新需求、流程、设计和验收用例；
3. 给出数据迁移、兼容与回滚方案；
4. 通过评审后再实施。
