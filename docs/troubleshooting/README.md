## 维护规则

- 先查本表，再按域查一份文档；跨域任务才读取多份。
- 在本地任务授权范围内，已验证且可复用的问题由 Skill 自动更新对应领域文档，无需逐条再次确认；这不授权提交、推送、发布或远端写入。
- 每条经验必须有稳定 ID、适用版本/环境、触发条件、可观察症状、已验证根因、安全解决方案、明确非解决方案、验证方法、预防项、证据链接和最后验证日期。
- 相同触发和根因优先更新已有条目；只有可复用且无法归入现有条目时才新增 ID。
- 一次性环境噪声写日期化验收记录，不污染长期知识库。
- 未验证根因或临时绕过只写入脱敏运行报告并标记 `open`，不得包装成解决方案。
- 产品/架构决定写 `docs/V2决策记录.md`；稳定项目规则写根 `AGENTS.md`。
- 不写密钥、Token、正文、真实用户 ID、原始敏感文件名或受保护映射。
