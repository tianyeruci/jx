# 小程序后端接口变动说明（新版交付文档）

> 适用范围：当前小程序后端对接 AI 管理服务的朋友圈顾问和日常写作工具。
> 课程 Excel、课程推荐、学习路线和旧会话不属于本轮范围。

### 通用请求头

以下请求头适用于本文所有接口：

```Plain
X-Internal-Token: <内部服务令牌>
X-User-Id: <小程序后端稳定用户 ID>
```

其中 `X-User-Id` 必须是小程序后端能够稳定提供的用户标识；不要把 Dify 原始用户标识或 Dify 原始 `conversation_id` 暴露给客户端。JSON 请求另外携带 `Content-Type: application/json`，SSE 请求另外携带 `Accept: text/event-stream`。

1. ## 朋友圈顾问

### 朋友圈顾问枚举

| 展示名称 | type 值 |
| --- | --- |
| 销售型朋友圈 | `sales` |
| 种草型朋友圈 | `seeding` |
| 润色 | `polish` |

1. ### 创建朋友圈顾问会话

**请求**

```Plain
POST /internal/v1/tools/moments/conversations
```

**请求头**

```Plain
X-Internal-Token: <内部服务令牌>
X-User-Id: <小程序后端稳定用户 ID>
Content-Type: application/json
```

**请求体**

```json
{"type":"sales"}
```

**type 可选值**

```Plain
sales
seeding
polish
```

**响应**

```json
{
  "conversation_id": "本地工具会话ID",
  "kind": "moments",
  "type": "sales",
  "output_format": "article",
  "guide": "把你今天想卖的产品、活动或者素材发给我，我直接帮你写。"
}
```

同一用户和工具已有相同类型/格式的当前会话时，重复 create 会幂等返回该会话；响应不包含 `is_new` 字段。

**小程序后端必须处理**

1. 保存返回的本地 `conversation_id`；
2. 保存当前 `type` 并展示 `guide`；
3. 后续 `/run` 把 `conversation_id` 放在请求体顶层；
4. 不要把 Dify 原始 `conversation_id` 暴露给小程序。

1. ### 查询当前朋友圈顾问会话

**请求**

```Plain
GET /internal/v1/tools/moments/conversations/current
```

请求头使用“通用请求头”；该请求不需要请求体。

**有当前会话时响应示例**

```json
{
  "conversation_id": "本地工具会话ID",
  "kind": "moments",
  "type": "seeding",
  "output_format": "article",
  "guide": "把你今天想卖的产品、活动或者素材发给我，我直接帮你写。"
}
```

**没有当前会话时响应示例**

```json
{
  "conversation_id": null,
  "kind": null,
  "type": null,
  "output_format": null,
  "guide": null
}
```

没有会话不是故障；此时展示三种类型，用户选择后再调用 create。

1. ### 重置朋友圈顾问会话

**请求**

```Plain
POST /internal/v1/tools/moments/conversations/{conversation_id}/reset
```

请求头使用“通用请求头”，`Content-Type: application/json`。

**请求体**

```json
{}
```

**响应**

```json
{
  "message": "已开启新会话",
  "conversation_id": null,
  "kind": "moments",
  "type": null,
  "output_format": null,
  "guide": null
}
```

**小程序后端必须处理**

- 清除本地旧 `conversation_id` 和页面历史；
- 重新展示类型选择；
- reset 后不会自动创建新会话，也不会保留旧类型；
- 旧路径 `POST /internal/v1/tools/moments/conversations/reset` 返回 `404`。

1. ### 朋友圈顾问生成接口

**请求**

```Plain
POST /internal/v1/tools/moments/run
Content-Type: application/json
Accept: text/event-stream
```

请求头还需携带“通用请求头”。

**请求体**

```json
{
  "conversation_id": "本地工具会话ID",
  "inputs": {
    "request": "今天店里做会员日活动，帮我写一条朋友圈。",
    "source_material": "满199减50，活动只限今天，主推修护精华。",
    "audience": "老客户",
    "tone": "自然",
    "constraints": "不要夸张"
  }
}
```

**请求字段**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `conversation_id` | string | 是 | 请求体顶层的本地会话 ID |
| `inputs.request` | string | 是 | 用户本轮需求 |
| `inputs.source_material` | string | 否 | 产品、活动、体验或原稿素材 |
| `inputs.audience` | string | 否 | 目标受众 |
| `inputs.tone` | string | 否 | 语气要求 |
| `inputs.constraints` | string | 否 | 长度、结构或禁用要求 |

`inputs` 禁止 `conversation_id`、`type`、`format`、`output_format`。类型以 create 时选择的会话类型为准；需要切换类型必须先 reset 再 create。

**SSE 事件**

```Plain
request_started
status
answer_delta
message_end
error
```

客户端按 SSE 事件边界解析，不要把一次网络分片当成完整 JSON。

**补充请求案例：种草型/润色**

```json
{
  "conversation_id": "本地工具会话ID",
  "inputs": {
    "request": "帮我把周末野餐体验写成一条种草朋友圈。",
    "source_material": "郊区草地，环境安静，适合带孩子，停车方便。"
  }
}
```

```json
{
  "conversation_id": "本地工具会话ID",
  "inputs": {
    "request": "帮我润色这条朋友圈，语气自然一点。",
    "source_material": "今天第一次参加线下活动，认识了很多新朋友。"
  }
}
```

1. ## 文本触发重置

在 `/run` 的 `inputs.request` 中，仅以下七个精确短语触发重置（允许首尾空白和句末标点）：

```Plain
新对话
开启新对话
开始新对话
新建对话
重新开始对话
重新开启对话
重开对话
```

“请开启一个新会话”“创建新会话”“开始写一篇新文章”等相似表达按普通内容处理，不触发 reset。触发后通过 SSE 返回“已开启新会话”，不调用 Dify。

1. ## 状态码与对接顺序

| 状态码 | 含义 | 客户端处理 |
| --- | --- | --- |
| `200` | current/create/reset 成功，或 SSE 已建立 | 按响应处理 |
| `401` | 内部令牌缺失或无效 | 检查 `X-Internal-Token` |
| `404` | 会话不存在、无权访问或旧 reset 路径 | 清除本地 ID并使用正式路径 |
| `409` | 已有会话但尝试修改类型/格式 | 先 reset，再 create |
| `422` | 字段位置/名称错误或未知字段 | 按本文修正请求体 |

推荐顺序：`current` → 用户选择 → `create` → 保存本地 ID → `/run` → SSE 解析；点击开启新会话时调用带 ID 的 reset。

**典型错误响应**

字段校验失败（例如把 `conversation_id` 错放进 `inputs`）时：

```json
{
  "detail": [
    {
      "type": "extra_forbidden",
      "loc": ["body", "inputs", "conversation_id"],
      "msg": "Extra inputs are not permitted"
    }
  ]
}
```

会话不存在或会话不属于当前用户时：

```json
{
  "code": "NOT_FOUND",
  "message": "会话不存在或无权访问",
  "request_id": "请求追踪ID",
  "retryable": false
}
```

已有会话但尝试修改类型/格式时：

```json
{
  "code": "CONFLICT",
  "message": "当前会话类型不可修改，请先开启新会话",
  "request_id": "请求追踪ID",
  "retryable": false
}
```
