# 顾问消息操作新增及变更接口清单

> 根据现有接口文档整理，仅列接口和主要变化；未列出的接口保持不变。

## 一、新增接口（3 个）

| 接口 | 主要内容 |
| --- | --- |
| `POST /internal/v1/business/messages/{message_id}/regenerate` | 商业顾问重新生成；覆盖原助手消息，本地消息 ID 不变。 |
| `POST /internal/v1/tools/{kind}/messages/{message_id}/feedback` | 朋友圈顾问、日常写作点赞、点踩和取消反馈。 |
| `POST /internal/v1/tools/{kind}/messages/{message_id}/regenerate` | 朋友圈顾问、日常写作重新生成；成功后返回新的工具消息 ID。 |

## 二、变更接口（8 个）

| 接口 | 主要变更 |
| --- | --- |
| `GET /internal/v1/entry-config` | 三类顾问增加或更新 `feedback`、`regenerate`、`stop` 能力字段。 |
| `GET /internal/v1/business/conversations/{conversation_id}/messages` | 每条消息增加 `can_regenerate`；原多消息结构和分页不变。 |
| `POST /internal/v1/business/chat` | 请求不变；失败 SSE 增加 `conversation_id`、`message_id` 和 `status=failed`。 |
| `POST /internal/v1/tools/moments/run` | 请求不变；SSE 增加 `task_id`、`message_id` 和明确终态。 |
| `POST /internal/v1/tools/writing/run` | 请求不变；SSE 增加 `task_id`、`message_id` 和明确终态。 |
| `POST /internal/v1/tools/{task_id}/stop` | 只停止当前用户的活动 Chat 任务；停止后原 SSE 返回 `stopped`。 |
| `POST /internal/v1/business/messages/{message_id}/feedback` | 请求不变；增加消息状态和并发校验。 |
| `POST /internal/v1/business/chat/{task_id}/stop` | 请求不变；同时支持普通生成和重新生成，并收紧重复停止处理。 |
